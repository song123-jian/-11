## 关键决策与约束

- V1.0 仍按已冻结范围交付；P2 属于 V1.1 及后续候选，不计入 16 周验收。工作台不向用户展示版本优先级标记，内部排序字段仅用于搜索排序。
- 方案技术基线保持 Tauri 2.x + Vue 3 + Pinia + Element Plus，敏感操作与长任务下沉 Rust；当前原型采用 Vue Composition API 与轻量自有样式，待桌面能力桥接阶段再按基线补齐状态层和组件库。
- 本地优先、默认不上传；云端 AI 与在线 OCR 必须展示供应商、传输内容和用途并取得明确授权。
- Supabase 云同步为可选能力但按默认建议路径实现：用户登录并同意云同步用途后自动同步 `assistant`、`tasks`、`ui-prefs`；首次恢复远端优先，登录后的本机脏数据优先，上传期间的新修改保留到下一轮；publishable/anon key 只从本机 `.env.local` 读取，禁止提交或使用 `service_role`。便签/会议正文、文件、API Key、中转站配置、诊断日志和翻译原文/译文均不上传；未配置、未授权或离线时本地功能不受影响。
- 应用内返回历史采用独立内存栈，最多保留 30 条已规范化的模块、工具、效率助手页签和文档模式标识；不进入 `storage.js` 白名单、不写入本地存储、不携带正文/文件/表单值。`Alt+←` 仅在非可编辑控件且无设置/授权弹窗时生效；文档任务忙碌期间切换仍受保护。
- 中转站 API 采用 OpenAI-compatible 契约（`/models` 与 `/chat/completions`）；Base URL 由用户配置，无路径的服务商根地址统一规范到 `/v1`，连接测试可在未填写模型时发现有效模型 ID；默认不内置服务商地址；API Key 强制仅保存在当前进程内存，不写入 `localStorage`、`sessionStorage` 或其他本机存储，保存/加载/清除配置时会清理旧版本遗留密钥，也可在设置页主动清除。
- 翻译助手沿用中转站的 OpenAI-compatible Chat Completions 契约，但联网授权使用独立 `translation` 作用域；语言/风格/格式偏好写入 `ui-prefs`，原文和译文只存在当前页面状态，只有用户主动点击“保存到便签”才写入便签。
- CC Switch 互通采用官方 `ccswitch://v1/import?resource=provider` 供应商深链接；本地数据库/SQL 仅在用户主动选择文件后读取 `providers` 表，数据库只读、SQL 在内存 SQLite 执行并拒绝高风险语句；导出链接/JSON 明文包含 API Key，界面在生成与复制处持续提示风险。
- Windows 协议唤起使用官方 `tauri-plugin-deep-link`，固定注册 `ccswitch` scheme；启动参数只返回首个合法 `ccswitch://v1/import` 链接给前端，限制 64 KiB，不记录、不持久化，前端继续执行 CC Switch 字段校验。
- 统一作业契约覆盖进度、取消、幂等结果、错误码与安全诊断；批量文件操作默认另存，覆盖或清理前必须预览、确认并提供恢复路径。
- 表格处理默认本地化和受限输入：XLSX 只读取首个工作表，旧版 `.xls` 不支持；单文件 50 MB、100,000 行、256 列和 20,000 字符单元格限制用于防止浏览器内存失控。
- 目标 KB 图片压缩是尽量逼近目标的编码策略，不承诺所有图片都能精确命中；相纸排版输出新 PNG，系统打印入口由浏览器/桌面环境决定。
- 用户已确认 PDF 进阶暂不补充或实施；本轮只保留既有 PDF 合并/拆分和打印路径。
- FR-G10 诊断包采用本地优先、手动导出边界：最多 30 条事件，字段与枚举固定白名单，导出前必须二次规范化；不得写入自由文本、正文、文件内容、完整路径、口令或密钥，不得自动上传或启用崩溃上报。
- 空闲崩溃诊断夹具只在用户明确启动时采集本地 stdout/stderr、Rust panic、WebView2 日志、进程树和 Windows 事件；进程命令行只保留存在性，避免深链接/API Key 泄露；诊断目录不自动上传。
- 提醒可靠性采用“双层调度”：前端 15 秒扫描负责即时状态和回退提示，Windows 桌面版将未来一次性提醒同步到当前用户 Task Scheduler；IPC 失败不确认指纹，下一轮继续重试；`--reminder-fire` 参数只接受受限提醒 ID，隐藏实例发送通知后退出。
- 便携模式只由 EXE 同目录的 `portable.flag` 显式开启，WebView2 数据写入同目录 `data\webview`；便携包不声明 Win7 兼容性或后台内存硬门禁，仍需 Windows 10/11 与 WebView2 Runtime。
- 性能目标是发布门禁，不得通过关闭签名/安全校验、降低输出质量或隐藏外部依赖体积达成。
- 启动、空闲和会话基线必须记录被测 EXE 的 SHA-256；`verify_release_gate.ps1` 必须逐份验证其与当前 EXE 一致，字段缺失或不一致均不得复用历史性能结果。
- 更新清单签名采用 Ed25519 detached signature；私钥只通过 `EFFICIENCY_UPDATE_SIGNING_PRIVATE_KEY` 指向的本地文件读取，不写入仓库或清单；综合门禁通过 `EFFICIENCY_UPDATE_PUBLIC_KEY_PATH` 调用独立验签工具核对清单原始字节；EXE/NSIS Authenticode 签名仍是独立门禁，任一签名未通过都不得判定 `releaseQualified=true`。
- Release 构建启用 LTO、单 codegen 单元、符号剥离和 `panic=abort`，用于降低发布包体积并保持可重复构建；该优化不改变运行时功能或发布签名要求。
- 评估采用硬门禁 + 100 分矩阵；硬门禁全部通过且综合得分不低于 85 分才允许发布，统计样本不足不得判定达标。
- 原始 V1.2 DOCX 不覆盖；生成物统一写入 `output/`。
- OpenPGP 口令加密替代自定义 AES/age 容器，采用成熟可互操作格式；Tesseract.js 与 OpenPGP 均按需加载，降低首屏负担。
- 显式联网端点限定为 Frankfurter/ECB 汇率、ipify 公网 IP、Cloudflare 测速和 Tesseract 模型 CDN；旧 Frankfurter 与 IPv4 ipify 端点因当前网络/CORS 实测不可用，已改为可达端点。
- Office 导出在目标 PDF 已存在时拒绝覆盖；ZIP 解压限制 500 个条目、单文件 128 MiB、总展开 256 MiB，避免意外覆盖和内存失控。
- 桌面批量重命名只生成副本，输出文件使用 `create_new` 防止竞态覆盖；浏览器模式仍保留 ZIP 归档重命名路径。
- 长截图使用浏览器 `getDisplayMedia` 授权和本地 Canvas 拼接，帧数限制为 2-8、间隔和开始延迟限制为 1-10 秒。
- FR-G08 核心路径补充跳过导航、程序化表单标签、设置弹窗焦点循环、24px 交互目标和减少动态效果支持；已完成 Chromium 640×800 等效 200% 重排及 1280×800 模块级可访问名称/目标尺寸巡检，但实际系统文本缩放、对比度和辅助技术验收仍需在冻结参考设备上完成。

## 已知限制、风险、阻塞和待办

- 已知限制：当前软件是可运行原型；当前 Release 已完成 20 次自动启动、10 分钟空闲和 200 次会话采样，均与当前 EXE 哈希绑定且通过。每个采样脚本创建并结束独立进程树；并行会争用 CPU/IO，不能替代隔离性能 P95。会话脚本以窗口句柄就绪作为启动边界并由夹具结束进程树，尚未冻结“主窗口内容可交互”的计时口径，也未覆盖真实用户操作链路；冻结参考设备、重复 RC 采样和更长期稳定性仍不能由当前设备证据替代。
- 已知限制：中转站 API 已完成配置、契约和本地模拟响应验证；用户提供密钥访问 `https://catbee.online/v1/models` 已返回 HTTP 200 和 30 个模型，但最小化真实 `/v1/chat/completions` 请求返回 HTTP 503 `Service temporarily unavailable`，因此聊天链路尚未完成外部成功验收；公开 Sub2API 文档默认示例前缀为 `sk-`，Cat Bee 是否自定义鉴权、配额、计费和服务商隐私条款仍未由服务商确认。用户提供的 API Key 未写入源码、日志、交接文档或发布包。
- 已知限制：CC Switch A+B+C 已完成脱敏规则、字段提取、SQL 备份和临时实际 SQLite 文件验收；尚未使用用户真实版本的 CC Switch 数据库或 SQL 备份做端到端样本验收，仍需用脱敏或临时供应商配置验证不同版本的 `settings_config` 结构。
